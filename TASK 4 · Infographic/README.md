#  Task 4 — Infographic

This project contains a visually engaging infographic designed to present information in a clear and easy-to-understand format.

## Features

* Clear title and sections
* Multiple data points
* Icons and visual elements
* Charts/diagrams
* Consistent colour scheme
* Logical visual flow
* Cited information
* High-resolution PNG

## Tools Used

* Figma
* Canva
* Adobe Illustrator

## Learning Outcome

Gained practical experience in **information design, data visualization, visual hierarchy, iconography, and layout**.
