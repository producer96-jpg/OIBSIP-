#  Task 2 — Logo Design

This project contains a minimalist logo design created for a fictional brand as part of the **Graphics Design Track**.

The logo focuses on simplicity, brand identity, typography, and scalability.

## Features

* Original logo concept
* Full-colour version
* Monochrome version
* Reversed version
* Vector SVG format
* Transparent PNG
* Defined colour palette

## Tools Used

* Figma
* Adobe Illustrator
* Canva

## Learning Outcome

Gained practical experience in **logo design, branding, typography, colour selection, and vector design**.
