#  Task 5 — Magazine / Brochure Layout

This project contains a multi-page magazine or brochure layout created as part of the **Graphics Design Track**.

The design focuses on editorial layout, typography, grids, imagery, and print design.

## Features

* Multi-page layout
* Consistent grid system
* Headers and footers
* Page numbers
* Full-bleed images
* Pull quote
* Typography hierarchy
* Consistent colour palette
* Multi-page PDF

## Tools Used

* Figma
* Canva
* Adobe InDesign

## Learning Outcome

Gained practical experience in **editorial design, grid systems, typography, image placement, and print-ready layout design**.
