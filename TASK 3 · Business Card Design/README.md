#  Task 3 — Business Card Design

This project contains a professional double-sided business card designed using the brand identity created for the logo project.

## Features

* Front and back design
* Company logo
* Name and job title
* Contact information
* Website and social media
* Consistent branding
* Proper print dimensions
* 3mm bleed
* Print-ready PDF

## Tools Used

* Figma
* Canva
* Adobe Illustrator

## Learning Outcome

Gained practical experience in **branding consistency, typography, whitespace, layout, and print design**.
