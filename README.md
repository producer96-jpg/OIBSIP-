# OIBSIP - Graphics Design Track

This repository contains the graphic design projects completed as part of my **Graphics Design Track**.

The projects were created using **Figma, Canva, Adobe Photoshop, and Adobe Illustrator** to practice visual design, branding, typography, layout, colour theory, and creative communication.

## Projects

### 1. Posters & Fliers

A collection of digital posters and promotional fliers created for different events, campaigns, or creative concepts.

**Features:**

* Multiple poster designs
* Defined colour palettes
* Clear visual hierarchy
* Custom graphic elements
* Typography and CTA design
* High-resolution exports
* Print and social media formats

**Tools:**

* Figma
* Canva
* Adobe Photoshop / Illustrator

---

### 2. Logo Design

A minimalist logo design created for a fictional brand with a focus on simplicity and brand identity.

**Features:**

* Original logo concept
* Full-colour version
* Monochrome version
* Reversed version
* Vector SVG format
* Transparent PNG
* Brand colour and typography

**Tools:**

* Figma
* Adobe Illustrator
* Canva

---

### 3. Business Card Design

A professional double-sided business card designed using the brand identity from the logo project.

**Features:**

* Front and back design
* Name and job title
* Contact information
* Social media details
* Consistent branding
* Proper print dimensions
* 3mm bleed area
* Print-ready PDF

**Tools:**

* Figma
* Canva
* Adobe Illustrator

---

### 4. Infographic

A visually engaging infographic designed to present information using graphics, icons, charts, and structured content.

**Features:**

* Clear title and sections
* Multiple data points
* Icons and visual elements
* Charts or diagrams
* Consistent colour scheme
* Logical visual flow
* Cited information
* High-resolution PNG

**Tools:**

* Figma
* Canva
* Adobe Illustrator

---

### 5. Magazine / Brochure Layout

A multi-page magazine or brochure layout created to demonstrate editorial design and print layout skills.

**Features:**

* Multi-page layout
* Consistent grid system
* Headers and footers
* Page numbers
* Full-bleed images
* Pull quotes
* Typography hierarchy
* Consistent branding
* Multi-page PDF

**Tools:**

* Figma
* Canva
* Adobe InDesign
